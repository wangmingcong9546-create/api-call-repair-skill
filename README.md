# Neo-Retro Pop 讲解剪辑台

把一篇商业或财务讲解稿变成一条波普图解动画。真人自己念，剪辑台负责画面。

风格已经做进引擎里：炭黑墨线、有限的平涂色、纸张颗粒、品牌色当主角。换片子只换一份 JSON，不用改代码。

## 打开

用 Chrome 或 Edge 双击打开 `studio.html`。

右侧是当前这句口播，对着念。「恢复示例」是一条十八幕的版式演示，里面的数字不是财报。

## 用自己的稿

把 `SKILL.md` 交给任意一个 AI，连同你的讲解稿。它应该只还你一份 JSON。贴进「脚本 JSON」，点「应用脚本」。

- 底栏切换 16:9、9:16、3:4。
- 真人站在画面一侧时，选「右侧留给真人」或「左侧留给真人」。
- 「导出全片」或「导出本章」得到 webm。很长的片子按章导出。
- 截图幕的 `src` 是文件名。点「载入图片」选中这些文件。

需要「Noto Sans CJK SC」才能和设计时的字重一致。没有的话会用苹方或微软雅黑。

## 文件

- `SKILL.md`：给别的 AI 看的分镜规范。
- `studio.html`：剪辑台。
- `src/`：渲染引擎。不要改，除非你在改风格本身。
- `demo_story.js`：示例故事。
